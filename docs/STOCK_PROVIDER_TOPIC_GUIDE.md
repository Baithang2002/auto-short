# Stock Provider Topic Guide

## Purpose

The daily pool favors topics that can be illustrated with several literal,
common search terms. It does not guarantee a successful run: provider inventory,
API quotas, downloads, and visual verification still change over time. The live
source-coverage and verified-media gates remain the final authority.

## Best Topic Families

- Common animals: bees, butterflies, frogs, birds, penguins, bears, elephants,
  dolphins, turtles, horses, deer, wolves, fish, owls, hummingbirds, crabs, and
  spiders.
- Common natural motion: waves, waterfalls, rivers, streams, rain, fog, clouds,
  snow, ice, rainbows, sunsets, and wind.
- Common landscapes: forests, beaches, mountains, lakes, caves, sand dunes,
  glaciers, volcanoes, geysers, and coral reefs.
- Common plant subjects: flowers, seeds, leaves, moss, mushrooms, bamboo, and
  trees.

## Why These Are Safer

Pexels documents video search for broad queries such as `Nature`, `Tigers`, and
`People`, with landscape/portrait filters and up to 80 results per page. Pixabay
documents video search with nature, science, education, animals, and places
categories, plus popular ordering and safe-search filtering. A live Pixabay
nature search currently exposes tens of thousands of results and literal tags
such as waterfall, forest, river, ocean, bird, butterfly, penguin, and frog.

Wikimedia Commons has broad animal, plant, natural-phenomena, astronomy, and
place collections, but each file has its own license and attribution rules.
Europeana is best treated as an archival/supporting source, not the primary
stock-video source.

## Avoid Without Preflight

- Rare species or very specific actions that require a single exact shot.
- Named locations, named people, brands, celebrities, and copyrighted fictional
  characters.
- Claims about disasters, accidents, war, medical procedures, or crime.
- Topics that require diagrams, satellite imagery, microscopic footage, or a
  precise historical artifact.
- Queries that combine several subjects, locations, or actions in one sentence.

## Licensing

Pexels asks API users to link to Pexels and credit photographers when possible.
Pixabay asks API users to show where search results came from and requires API
responses to be cached for 24 hours. Wikimedia requires checking each file's
license, attribution, and possible non-copyright restrictions. The pipeline
must preserve provider provenance and should not treat a search result as a
blanket commercial-use guarantee.
