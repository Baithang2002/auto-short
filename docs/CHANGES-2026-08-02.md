# What We Changed — 2026-08-02

Session scope: harden unattended daily publishing, diagnose the first production failure, and return the pipeline to a green production run. All work is merged to `main` (commits `664f5d3`, `5e3c383`) and verified with 493 passing tests.

## 1. Reliability hardening (commit `664f5d3`)

- **Workflows.** Daily and qualification jobs check out the current `main` tip after acquiring their concurrency lock and select the production render profile explicitly; non-main blank manual dispatches are rejected; topics pass via environment variables; per-attempt timeout budgets fit inside job limits.
- **Coverr.** Switched to the supported `/videos` endpoint with signed URLs, required download URL, attribution, and hard-stop after rate-limit failures.
- **Vision.** Gemini falls back to Groq's `qwen/qwen3.6-27b` multimodal model with structured JSON validation; malformed verifier output is treated as unavailable, never as a false visual mismatch.
- **Source coverage.** Failures are classified as technical only when a provider outage leaves a scene inconclusive; healthy-but-rejected candidates remain content gaps so the scheduler rotates topics.
- **Voice.** Provider registries are reused for the full narration run (AudioLab/ElevenLabs circuit state survives across segments); AudioLab rejects empty responses.
- **Media.** Replacement downloads preserve the accepted destination until fully downloaded; rejected verified-media replacements restore the original clip.
- **Clip deduplication.** `state/used_videos.json` is the single canonical path, keeps stable provider IDs, drops ephemeral runner paths; IDs lost in the AudioLab merge were restored.
- **Uploads.** Deterministic date-and-slot publish keys with a pre-insert idempotency check; scheduled uploads use the no-music variant by default; duplicate uploads skip the engagement comment; the publish-key marker survives description truncation.
- **Rendering.** Scene-count-aware bounded ffmpeg timeout; GitHub production runs sample up to four final rendered SHOW/REVEAL/PROVE frames; only explicit transient quota/rate-limit signals take the warning path.
- **CLI parity.** Direct CLI runs enforce source-coverage deferrals by default, matching scheduled production behavior.
